# 12.3 `curator.py` — the solver, the sampler, and the sealing bridge

This is where 12.1 (the scorecard) and 12.2 (the constraint YAML) actually collide with a bank of candidate phrases and produce a promoted `phrase_bank.vN.jsonl`. Everything upstream is metadata; everything downstream is downstream of *this file*. Which means it has to do three unglamorous things extremely well:

1. **Solve** — given a candidate pool and a constraint YAML, decide which phrases to admit, which to eject, and which to hold in reserve, using a bounded greedy sampler with a repair pass. Not an ILP — we tried, the runtime blew up past 8k candidates. Greedy + repair converges in under 40s on a 30k-candidate pool and gets within 2% of the ILP optimum on the golden test set.
2. **Sample** — the greedy step needs a scoring function that mixes scorecard quality, constraint marginal-utility, and a small stochastic jitter so consecutive runs on identical inputs don't produce identical banks (bad for downstream diversity metrics). Reproducibility comes from a seeded RNG, not from determinism.
3. **Seal** — every accepted phrase, every ejected phrase, and every constraint decision gets a row appended to `_lora_ledger.csv` through `seal_ledger.append_sealed()` from Part 10. The phrase bank is not a special snowflake; it lives on the same chained-hash ledger as the LoRA manifest. One integrity story for the whole pipeline.

### 12.3.3 Loading — candidates, current bank, config

```python
def load_candidates(path: Path) -> list[Candidate]:
    """Read phrase_bank.vN.candidate.jsonl — one JSON object per line."""
    cands: list[Candidate] = []
    with path.open("r", encoding="utf-8") as fh:
        for lineno, line in enumerate(fh, 1):
            line = line.strip()
            if not line or line.startswith("//"):
                continue
            try:
                obj = json.loads(line)
            except json.JSONDecodeError as e:
                log.error("candidate line %d malformed: %s", lineno, e)
                continue
            try:
                cands.append(Candidate(
                    phrase_id=obj["phrase_id"],
                    text=obj["text"],
                    phonemes=list(obj.get("phonemes", [])),
                    duration_ms=int(obj["duration_ms"]),
                    scorecard=obj["scorecard"],
                    tags=list(obj.get("tags", [])),
                    source=obj.get("source", ""),
                    created_at=obj.get("created_at", ""),
                ))
            except KeyError as e:
                log.error("candidate line %d missing field %s", lineno, e)
    log.info("loaded %d candidates from %s", len(cands), path.name)
    return cands


def load_current_bank(path: Path) -> dict[str, Candidate]:
    """Load the currently-promoted bank so eject decisions can reference it."""
    if not path.exists():
        log.info("no current bank at %s — starting from empty", path)
        return {}
    bank: dict[str, Candidate] = {}
    with path.open("r", encoding="utf-8") as fh:
        for line in fh:
            line = line.strip()
            if not line:
                continue
            obj = json.loads(line)
            bank[obj["phrase_id"]] = Candidate(
                phrase_id=obj["phrase_id"],
                text=obj["text"],
                phonemes=list(obj.get("phonemes", [])),
                duration_ms=int(obj["duration_ms"]),
                scorecard=obj["scorecard"],
                tags=list(obj.get("tags", [])),
                source=obj.get("source", ""),
                created_at=obj.get("created_at", ""),
            )
    log.info("loaded %d existing bank entries", len(bank))
    return bank


def load_config(path: Path) -> tuple[dict, str]:
    """Return (parsed config, sha256 of raw bytes). The sha lands in the ledger."""
    raw = path.read_bytes()
    sha = hashlib.sha256(raw).hexdigest()
    cfg = yaml.safe_load(raw)
    return cfg, sha
```

The `config_sha` is doing quiet work here — every ledger row from this run carries it, so six months from now when someone asks "why did we eject phrase 4a71 in September," `diff_curator_reports.py` can retrieve the exact YAML that was live at decision time, not the YAML that happens to be on disk today.

### 12.3.4 Scoring — composite, marginal, phoneme gap

The greedy sampler needs a single scalar per candidate at each step. That scalar is a weighted sum of three things:

- **Intrinsic quality** — the scorecard composite from 12.1, in `[0, 1]`.
- **Marginal utility** — how much this candidate *reduces* the current gap between the admitted set and the constraint targets. A candidate that fills an underrepresented phoneme scores higher than a candidate that saturates an already-full bucket.
- **Jitter** — a tiny seeded noise term so ties break stochastically and consecutive runs explore slightly different corners of the solution space.

```python
def phoneme_gap(state: SolverState, targets: dict[str, dict]) -> dict[str, float]:
    """
    For each target phoneme, return the deficit in [0, 1].
    1.0 = phoneme is completely absent from admitted set; 0.0 = at or above target.
    """
    gaps: dict[str, float] = {}
    admitted_total = max(len(state.admitted), 1)
    for phoneme, spec in targets.items():
        target_freq = float(spec.get("min_frequency", 0.0))
        current_freq = state.phoneme_coverage.get(phoneme, 0) / admitted_total
        gaps[phoneme] = max(0.0, (target_freq - current_freq) / target_freq) if target_freq > 0 else 0.0
    return gaps


def marginal_utility(cand: Candidate, state: SolverState, cfg: dict) -> tuple[float, list[str]]:
    """
    Return (utility in [0, 1], list of axis names this candidate helps).
    """
    touched: list[str] = []
    utility = 0.0

    # Phoneme coverage contribution
    phoneme_targets = cfg.get("phoneme_targets", {})
    gaps = phoneme_gap(state, phoneme_targets)
    phoneme_bonus = 0.0
    for p in cand.phoneme_set:
        if p in gaps and gaps[p] > 0:
            phoneme_bonus += gaps[p]
            touched.append(f"phoneme:{p}")
    # Normalize by number of target phonemes so long phrases don't dominate
    if phoneme_targets:
        phoneme_bonus /= len(phoneme_targets)
    utility += cfg["weights"]["phoneme_coverage"] * phoneme_bonus

    # Axis-balance contribution — every categorical axis (tone, register, length_bucket)
    for axis_name, axis_spec in cfg.get("axes", {}).items():
        bucket = _bucket_for(cand, axis_name, axis_spec)
        if bucket is None:
            continue
        current = state.counters[axis_name].get(bucket, 0)
        target = axis_spec["buckets"][bucket].get("target_count", 0)
        if target > 0 and current < target:
            deficit = (target - current) / target
            utility += cfg["weights"]["axis_balance"] * deficit / len(cfg["axes"])
            touched.append(f"{axis_name}:{bucket}")

    return min(utility, 1.0), touched


def composite_score(cand: Candidate, state: SolverState, cfg: dict, rng: random.Random) -> tuple[float, list[str]]:
    """Blend intrinsic quality, marginal utility, and jitter into one scalar."""
    w = cfg["weights"]
    quality = cand.quality
    utility, touched = marginal_utility(cand, state, cfg)
    jitter = rng.uniform(-w.get("jitter", 0.02), w.get("jitter", 0.02))
    score = w["quality"] * quality + w["marginal"] * utility + jitter
    return score, touched


def _bucket_for(cand: Candidate, axis_name: str, axis_spec: dict) -> Optional[str]:
    """Bucketing dispatch — length_bucket, tone, register, etc."""
    if axis_name == "length_bucket":
        for name, spec in axis_spec["buckets"].items():
            lo, hi = spec["duration_ms_range"]
            if lo <= cand.duration_ms < hi:
                return name
        return None
    # Tag-driven axes — first matching tag wins
    for name in axis_spec["buckets"]:
        if name in cand.tags:
            return name
    return None
```

Two design choices worth calling out here. First, `marginal_utility` normalizes phoneme contribution by the *number of target phonemes*, not by the phrase's phoneme count — otherwise a 40-phoneme phrase would trivially outscore an 8-phoneme phrase even when the short one carries a rarer sound. Second, the jitter band is tiny by default (±0.02) but exposed in the config so you can widen it during exploration runs.

### 12.3.5 The solver — greedy admit with hard-constraint gating

```python
def solve(candidates: list[Candidate], current_bank: dict[str, Candidate],
          cfg: dict, rng: random.Random) -> SolverState:
    """
    Greedy admit loop. Every iteration:
      1. Rescore every remaining candidate against current state.
      2. Pick the highest-scoring candidate that violates zero hard constraints.
      3. Admit it, update state, log a Decision.
      4. Stop when target size reached or no admissible candidate remains.
    """
    target_size = cfg["bank"]["target_size"]
    hard = cfg.get("hard_constraints", {})
    max_duration_ms = hard.get("max_total_duration_ms", 10**9)
    max_per_source = hard.get("max_per_source", target_size)

    state = SolverState(
        admitted={},
        counters=defaultdict(Counter),
        phoneme_coverage=Counter(),
    )

    # Seed state with any pre-locked entries from the current bank
    locked_ids = set(cfg.get("locked_phrase_ids", []))
    for pid in locked_ids:
        if pid in current_bank:
            _admit(state, current_bank[pid], cfg,
                   reason="locked", score=1.0, touched=["locked"])

    remaining = [c for c in candidates if c.phrase_id not in state.admitted]
    source_counts: Counter = Counter(c.source for c in state.admitted.values())

    iteration = 0
    while len(state.admitted) < target_size and remaining:
        iteration += 1
        scored: list[tuple[float, Candidate, list[str]]] = []
        for cand in remaining:
            score, touched = composite_score(cand, state, cfg, rng)
            scored.append((score, cand, touched))
        scored.sort(key=lambda t: t[0], reverse=True)

        admitted_this_pass = False
        for score, cand, touched in scored:
            # Hard constraint gate
            if state.total_duration_ms + cand.duration_ms > max_duration_ms:
                continue
            if source_counts[cand.source] >= max_per_source:
                state.decisions.append(Decision(
                    phrase_id=cand.phrase_id, action="reject",
                    score=score, reason=f"source_cap:{cand.source}",
                    constraints_touched=touched,
                ))
                remaining.remove(cand)
                continue
            if _violates_hard_axis_cap(cand, state, cfg):
                remaining.remove(cand)
                state.decisions.append(Decision(
                    phrase_id=cand.phrase_id, action="reject",
                    score=score, reason="axis_cap",
                    constraints_touched=touched,
                ))
                continue

            _admit(state, cand, cfg, reason="greedy_admit", score=score, touched=touched)
            source_counts[cand.source] += 1
            remaining.remove(cand)
            admitted_this_pass = True
            break

        if not admitted_this_pass:
            log.warning("solver stuck at %d/%d admitted after %d iters",
                        len(state.admitted), target_size, iteration)
            break

        if iteration % 250 == 0:
            log.info("iter %d admitted=%d remaining=%d",
                     iteration, len(state.admitted), len(remaining))

    log.info("greedy phase done: admitted=%d target=%d iters=%d",
             len(state.admitted), target_size, iteration)
    return state


def _admit(state: SolverState, cand: Candidate, cfg: dict,
           reason: str, score: float, touched: list[str]) -> None:
    state.admitted[cand.phrase_id] = cand
    state.total_duration_ms += cand.duration_ms
    for p in cand.phonemes:
        state.phoneme_coverage[p] += 1
    for axis_name, axis_spec in cfg.get("axes", {}).items():
        bucket = _bucket_for(cand, axis_name, axis_spec)
        if bucket:
            state.counters[axis_name][bucket] += 1
    state.decisions.append(Decision(
        phrase_id=cand.phrase_id, action="admit",
        score=score, reason=reason,
        constraints_touched=touched,
        marginal_utility=score,
    ))


def _violates_hard_axis_cap(cand: Candidate, state: SolverState, cfg: dict) -> bool:
    for axis_name, axis_spec in cfg.get("axes", {}).items():
        bucket = _bucket_for(cand, axis_name, axis_spec)
        if not bucket:
            continue
        cap = axis_spec["buckets"][bucket].get("max_count")
        if cap is not None and state.counters[axis_name][bucket] >= cap:
            return True
    return False
```

The greedy loop terminates in three ways: target size reached (happy path), candidate pool exhausted (bank undersized — repair pass will not help, run report flags it), or no admissible candidate remained on a full pass (every remaining candidate violated a hard cap — repair pass runs next).

### 12.3.6 Repair pass — swap-based healing

Greedy alone leaves soft-constraint deficits: phoneme coverage under target, axis bucket short by two, that kind of thing. The repair pass looks at every unmet soft constraint and asks: *is there a swap — eject one admitted phrase, admit one rejected candidate — that improves the deficit without violating hard caps and without lowering total quality by more than `repair.max_quality_drop`?*
