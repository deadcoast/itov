## 12.0 Why this exists

`phrase_bank.jsonl` is the fixed probe set that `scorecard.py` reads from — every LoRA under audio-sync evaluation gets rendered against the same N phrases so scores are comparable across time. That only works if the bank itself is:

1. **Phonemically balanced** — every ARPAbet phoneme appears with at least a floor frequency, or LoRAs that happen to weaken specific phonemes (sibilants, plosives, nasals) go undetected because the bank never stresses them.
2. **Length-stratified** — short (≤ 6 words), medium (7–14), long (15–24). Long phrases stress drift; short phrases stress attack transients.
3. **Emotionally spread** — neutral, whispered, shouted, laughing, breathy. Voice LoRAs regress differently across affect.
4. **Deduplicated** — no two phrases within Levenshtein-normalized distance of 0.15.
5. **Provenance-tagged** — where each phrase came from (hand-authored, CMUdict-derived, LibriTTS-sampled, NSFW-hand-authored), because when a bias shows up you need to trace it.
6. **Rotationally versioned** — the bank is *frozen* per epoch. A curator that silently swaps phrases invalidates every historical scorecard. New phrases enter via explicit `bank_bump` events with a new version tag.

## 12.1 The phrase record schema

Every line in every `.jsonl` under this subsystem is a `PhraseRecord`. This is the single canonical schema — sources, staging, banks, all conform. Divergent schemas are how curation dies quietly.

```json
{
  "phrase_id": "ph_7f3a2c9e",
  "text": "She sells seashells by the shore, and the shells she sells are surely seashells.",
  "phonemes": ["SH", "IY", "S", "EH", "L", "Z", "S", "IY", "S", "EH", "L", "Z", "..."],
  "phoneme_counts": {"SH": 4, "S": 8, "IY": 3, "EH": 4, "L": 4, "Z": 2, "...": 0},
  "word_count": 14,
  "length_bucket": "medium",
  "affect": "neutral",
  "source": "hand_authored",
  "source_line": 42,
  "provenance_notes": "classic sibilant stress test",
  "nsfw": false,
  "estimated_duration_s": 4.8,
  "difficulty_score": 0.73,
  "content_hash": "sha256:9a4c...",
  "created_at": "2026-09-21T08:04:11Z",
  "curator_version": "0.4.2"
}
```

Field-by-field, because half these choices matter later:

| Field | Type | Purpose |
| --- | --- | --- |
| `phrase_id` | string, `ph_` + 8-hex | Stable ID derived from `sha256(text_normalized)[:8]`. Deterministic — same phrase always gets the same ID across sources. |
| `text` | string | Raw human-readable phrase. UTF-8. No leading/trailing whitespace. Punctuation preserved. |
| `phonemes` | list[str] | ARPAbet sequence from CMUdict lookup, `g2p_en` fallback for OOV. Stress markers stripped (`AH1` → `AH`). |
| `phoneme_counts` | dict[str,int] | Precomputed histogram. Curator reads this hot; recomputing per phrase during balancing is the difference between a 400ms audit and a 40s one on a 10k-phrase pool. |
| `word_count` | int | `len(text.split())` after normalization. |
| `length_bucket` | enum | `short` (≤6) \| `medium` (7–14) \| `long` (15–24). Phrases > 24 words rejected at ingest. |
| `affect` | enum | `neutral` \| `whispered` \| `shouted` \| `laughing` \| `breathy` \| `moaned` \| `strained`. Curator uses this to hit `affect_targets.json` floors. |
| `source` | enum | `hand_authored` \| `cmudict_derived` \| `libritts_sampled` \| `nsfw_hand_authored`. Immutable after ingest. |
| `source_line` | int | Line number in origin file. Traceability for when a bad phrase surfaces. |
| `provenance_notes` | string | Free-text why this exists. Curator writes short notes ("added for AA coverage"); humans write longer ones. |
| `nsfw` | bool | Routing flag. NSFW LoRAs get evaluated against the union of banks; SFW LoRAs only against `nsfw:false`. |
| `estimated_duration_s` | float | Rough TTS-duration prediction from `word_count * 0.34 + phoneme_count * 0.06`. Used to budget scorecard batch time upstream. |
| `difficulty_score` | float | 0.0–1.0. Blend of `phoneme_entropy × sibilant_density × length_penalty`. Curator uses it to force representation of hard phrases in every bank version. |
| `content_hash` | string | `sha256(text_normalized)` full hex. Ledger integrity anchor. Feeds into Part 10's chain when a bank is promoted. |
| `created_at` | ISO-8601 UTC | When the record was minted. |
| `curator_version` | semver | Which curator build produced this record. Lets us reprocess a source when the phonemizer changes without silently mixing schemas. |

Two normalization rules that the ID hash depends on — they're worth pinning down because if they drift the whole ID space collapses:

**Text normalization for `content_hash` and `phrase_id`:**

```txt
1. NFKC unicode normalize
2. collapse internal whitespace → single space
3. strip leading/trailing whitespace
4. lowercase
5. strip trailing punctuation (.,!?;:—)
6. keep internal apostrophes and hyphens
```

So `"She sells seashells."`, `"she sells seashells"`, and `"SHE  SELLS SEASHELLS!"` all hash to the same ID. This is deliberate — three sources contributing the same phrase should collapse to one record, with `provenance_notes` accumulating.

**Phoneme normalization:**

```txt
1. CMUdict lookup first (most common pronunciation only, drop alternates)
2. g2p_en fallback for OOV
3. strip stress digits (AH0, AH1, AH2 → AH)
4. no silence tokens, no word boundaries — just the flat sequence
```

The `phoneme_counts` dict includes every ARPAbet symbol observed anywhere in the bank as a key, with `0` for phonemes absent from this particular phrase. That fixed-key shape makes the coverage matrix a single numpy `stack()` instead of a dict-merge loop — matters at 10k phrases.

A minimal `PhraseRecord` dataclass, since every script in this subsystem imports it:

```python
# D:\AI\ComfyUI_portable\workshop\scrape\phrases\bin\phrase_record.py
from __future__ import annotations
from dataclasses import dataclass, field, asdict
from datetime import datetime, timezone
from typing import Literal
import hashlib
import json
import re
import unicodedata

CURATOR_VERSION = "0.4.2"

ARPABET_SYMBOLS = [
    "AA","AE","AH","AO","AW","AY","B","CH","D","DH","EH","ER","EY","F","G",
    "HH","IH","IY","JH","K","L","M","N","NG","OW","OY","P","R","S","SH","T",
    "TH","UH","UW","V","W","Y","Z","ZH",
]

LengthBucket = Literal["short","medium","long"]
Affect = Literal["neutral","whispered","shouted","laughing","breathy","moaned","strained"]
Source = Literal["hand_authored","cmudict_derived","libritts_sampled","nsfw_hand_authored"]

_PUNCT_TRAIL_RE = re.compile(r"[.,!?;:—\-]+$")
_WS_RE = re.compile(r"\s+")

def normalize_text_for_hash(text: str) -> str:
    t = unicodedata.normalize("NFKC", text)
    t = _WS_RE.sub(" ", t).strip().lower()
    t = _PUNCT_TRAIL_RE.sub("", t).strip()
    return t

def compute_phrase_id(text: str) -> str:
    norm = normalize_text_for_hash(text)
    return "ph_" + hashlib.sha256(norm.encode("utf-8")).hexdigest()[:8]

def compute_content_hash(text: str) -> str:
    norm = normalize_text_for_hash(text)
    return "sha256:" + hashlib.sha256(norm.encode("utf-8")).hexdigest()

def bucket_for(word_count: int) -> LengthBucket:
    if word_count <= 6: return "short"
    if word_count <= 14: return "medium"
    return "long"

@dataclass
class PhraseRecord:
    phrase_id: str
    text: str
    phonemes: list[str]
    phoneme_counts: dict[str, int]
    word_count: int
    length_bucket: LengthBucket
    affect: Affect
    source: Source
    source_line: int
    provenance_notes: str
    nsfw: bool
    estimated_duration_s: float
    difficulty_score: float
    content_hash: str
    created_at: str
    curator_version: str = CURATOR_VERSION

    @classmethod
    def build(
        cls,
        text: str,
        phonemes: list[str],
        affect: Affect,
        source: Source,
        source_line: int,
        nsfw: bool,
        provenance_notes: str = "",
        difficulty_score: float = 0.0,
    ) -> "PhraseRecord":
        wc = len(text.split())
        counts = {sym: 0 for sym in ARPABET_SYMBOLS}
        for p in phonemes:
            if p in counts:
                counts[p] += 1
        est_dur = round(wc * 0.34 + len(phonemes) * 0.06, 3)
        return cls(
            phrase_id=compute_phrase_id(text),
            text=text.strip(),
            phonemes=phonemes,
            phoneme_counts=counts,
            word_count=wc,
            length_bucket=bucket_for(wc),
            affect=affect,
            source=source,
            source_line=source_line,
            provenance_notes=provenance_notes,
            nsfw=nsfw,
            estimated_duration_s=est_dur,
            difficulty_score=round(difficulty_score, 4),
            content_hash=compute_content_hash(text),
            created_at=datetime.now(timezone.utc).isoformat(timespec="seconds"),
        )

    def to_jsonl(self) -> str:
        return json.dumps(asdict(self), ensure_ascii=False, sort_keys=True)

    @classmethod
    def from_jsonl(cls, line: str) -> "PhraseRecord":
        return cls(**json.loads(line))
```

One deliberate choice worth flagging: `phoneme_counts` stores the full `ARPABET_SYMBOLS` key set with zeros for absent phonemes, not just present ones. It roughly doubles the on-disk size of a `phrase_bank.jsonl` (about 2 KB per record instead of 1 KB), but it means `dedupe_scan.py` and `phoneme_audit.py` can build the coverage matrix by stacking dict-values in a single numpy call rather than a merge loop, which is roughly a 40× speedup on the pool sizes we're heading toward. Storage is cheap; audit-loop latency is what determines whether the curator gets run nightly or gets skipped when the operator is tired.
