## 13.1 Why Audio Sync Gates Promotion

Any LoRA carrying the `audio_reactive` tag (voice-cloned characters, lip-synced dialogue, moaning/breathing overlays, ASMR-style whisper models) has to prove it can lip-sync at production quality *before* it enters the prod pool. The failure mode we're preventing: a beautifully rendered clip where the mouth flaps a half-beat behind the audio and the entire scene reads as uncanny puppetry. Once that ships downstream to a batch render, you burn 40 minutes of 5090 wall-time on a clip that has to be scrapped.

The gate is three overlapping metrics fused into a single scorecard the promotion pipeline can accept or reject.

### 13.1.1 The Three Metrics

| Metric | What it measures | Tool | Pass threshold |
| --- | --- | --- | --- |
| **SyncNet offset** | Frame-level lip/audio alignment in ms | SyncNet v2 | \|offset\| ≤ 40 ms |
| **SyncNet confidence** | How certain the network is the audio and video belong together | SyncNet v2 | conf ≥ 7.0 |
| **Phoneme alignment F1** | How well wav2vec2 phonemes land on visual visemes | wav2vec2 + viseme map | F1 ≥ 0.82 |
| **Predicted MOS** | Perceptual mean opinion score, no reference needed | NISQA-derived | MOS ≥ 3.8 |

Any single metric failing → LoRA lands in `flag_review` bucket. Two or more failing → auto-quarantine. All four passing → clean promotion.

```python
# audio_sync/syncnet_wrapper.py
"""
Thin nn.Module wrapper around SyncNet v2.

Public API:
    load(cfg) -> SyncNet
    score(model, video_path, audio_path) -> SyncNetResult
"""
from __future__ import annotations

import logging
import subprocess
import tempfile
from dataclasses import dataclass
from pathlib import Path

import numpy as np
import torch
import torch.nn as nn
import torchaudio
import cv2

log = logging.getLogger("syncnet")


@dataclass
class SyncNetResult:
    offset_ms:      float
    confidence:     float
    frames_scored:  int
    audio_seconds:  float
    device:         str
    fp16:           bool


class SyncNet(nn.Module):
    """SyncNet v2 architecture — 5-frame windowed audio/video correlation."""

    def __init__(self):
        super().__init__()
        self.audio_encoder = nn.Sequential(
            nn.Conv2d(1,  64, (3, 3), padding=1), nn.BatchNorm2d(64),  nn.ReLU(inplace=True),
            nn.Conv2d(64, 128, (3, 3), padding=1), nn.BatchNorm2d(128), nn.ReLU(inplace=True),
            nn.MaxPool2d((3, 3), stride=(1, 2)),
            nn.Conv2d(128, 256, (3, 3), padding=1), nn.BatchNorm2d(256), nn.ReLU(inplace=True),
            nn.Conv2d(256, 256, (3, 3), padding=1), nn.BatchNorm2d(256), nn.ReLU(inplace=True),
            nn.MaxPool2d((3, 3), stride=(1, 2)),
            nn.Conv2d(256, 512, (3, 3), padding=1), nn.BatchNorm2d(512), nn.ReLU(inplace=True),
            nn.AdaptiveAvgPool2d(1),
        )
        self.video_encoder = nn.Sequential(
            nn.Conv3d(3,  64, (5, 7, 7), stride=(1, 2, 2), padding=(2, 3, 3)),
            nn.BatchNorm3d(64), nn.ReLU(inplace=True),
            nn.MaxPool3d((1, 3, 3), stride=(1, 2, 2)),
            nn.Conv3d(64, 128, (1, 3, 3), padding=(0, 1, 1)),
            nn.BatchNorm3d(128), nn.ReLU(inplace=True),
            nn.Conv3d(128, 256, (1, 3, 3), padding=(0, 1, 1)),
            nn.BatchNorm3d(256), nn.ReLU(inplace=True),
            nn.MaxPool3d((1, 3, 3), stride=(1, 2, 2)),
            nn.Conv3d(256, 512, (1, 3, 3), padding=(0, 1, 1)),
            nn.BatchNorm3d(512), nn.ReLU(inplace=True),
            nn.AdaptiveAvgPool3d(1),
        )
        self.audio_head = nn.Linear(512, 1024)
        self.video_head = nn.Linear(512, 1024)

    def forward_audio(self, mel: torch.Tensor) -> torch.Tensor:
        z = self.audio_encoder(mel).flatten(1)
        return nn.functional.normalize(self.audio_head(z), dim=1)

    def forward_video(self, frames: torch.Tensor) -> torch.Tensor:
        z = self.video_encoder(frames).flatten(1)
        return nn.functional.normalize(self.video_head(z), dim=1)


def load(cfg: dict) -> SyncNet:
    weights_path = Path(cfg["paths"]["models_dir"]) / cfg["models"]["syncnet"]["weights"]
    model = SyncNet()
    state = torch.load(weights_path, map_location="cpu")
    model.load_state_dict(state["model"] if "model" in state else state)
    device = cfg["models"]["syncnet"]["device"]
    model = model.to(device)
    if cfg["models"]["syncnet"]["fp16"]:
        model = model.half()
    model.eval()
    log.info("SyncNet v2 loaded from %s on %s (fp16=%s)",
             weights_path, device, cfg["models"]["syncnet"]["fp16"])
    return model


def _extract_mel(audio_path: Path, sr: int = 16000) -> torch.Tensor:
    wav, orig_sr = torchaudio.load(str(audio_path))
    if orig_sr != sr:
        wav = torchaudio.functional.resample(wav, orig_sr, sr)
    if wav.shape[0] > 1:
        wav = wav.mean(dim=0, keepdim=True)
    mel = torchaudio.transforms.MelSpectrogram(
        sample_rate=sr, n_fft=512, hop_length=160, n_mels=80,
    )(wav)
    mel = torch.log(mel.clamp_min(1e-5))
    return mel.unsqueeze(0)  # (1, 1, 80, T)


def _extract_mouth_crops(video_path: Path, fps: int = 24) -> tuple[torch.Tensor, int]:
    cap = cv2.VideoCapture(str(video_path))
    frames = []
    face_cascade = cv2.CascadeClassifier(
        cv2.data.haarcascades + "haarcascade_frontalface_default.xml"
    )
    while True:
        ok, frame = cap.read()
        if not ok:
            break
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        faces = face_cascade.detectMultiScale(gray, 1.1, 5)
        if len(faces) == 0:
            continue
        x, y, w, h = max(faces, key=lambda r: r[2] * r[3])
        # crop lower half of face for mouth region
        mouth = frame[y + h // 2 : y + h, x : x + w]
        mouth = cv2.resize(mouth, (112, 112))
        mouth = cv2.cvtColor(mouth, cv2.COLOR_BGR2RGB)
        frames.append(mouth)
    cap.release()
    if not frames:
        raise RuntimeError(f"no face detected in {video_path}")
    arr = np.stack(frames).astype(np.float32) / 255.0
    tensor = torch.from_numpy(arr).permute(3, 0, 1, 2).unsqueeze(0)  # (1, 3, T, 112, 112)
    return tensor, len(frames)


@torch.inference_mode()
def score(model: SyncNet, video_path: Path, audio_path: Path,
          cfg: dict) -> SyncNetResult:
    device = cfg["models"]["syncnet"]["device"]
    fp16   = cfg["models"]["syncnet"]["fp16"]
    dtype  = torch.float16 if fp16 else torch.float32

    mel   = _extract_mel(audio_path).to(device, dtype=dtype)
    video, n_frames = _extract_mouth_crops(video_path)
    video = video.to(device, dtype=dtype)

    audio_emb = model.forward_audio(mel.squeeze(1).unsqueeze(1))       # (1, 1024)
    video_emb = model.forward_video(video)                              # (1, 1024)

    # sliding-window offset search: ±15 frames = ±625 ms at 24 fps
    max_shift = 15
    correlations = []
    for shift in range(-max_shift, max_shift + 1):
        # shift audio window and re-embed a rolled slice
        shifted = torch.roll(mel, shifts=shift * 4, dims=-1)  # 4 mel frames per video frame
        emb = model.forward_audio(shifted.squeeze(1).unsqueeze(1))
        correlations.append(torch.nn.functional.cosine_similarity(emb, video_emb).item())

    correlations = np.array(correlations)
    peak_idx = int(np.argmax(correlations))
    peak     = float(correlations[peak_idx])
    offset_frames = peak_idx - max_shift
    offset_ms = offset_frames * (1000.0 / cfg["test_matrix"]["fps"])

    # confidence = peak minus median of distribution (robust separability)
    confidence = float((peak - np.median(correlations)) * 10.0)

    return SyncNetResult(
        offset_ms=offset_ms,
        confidence=confidence,
        frames_scored=n_frames,
        audio_seconds=mel.shape[-1] * 160.0 / 16000.0,
        device=device,
        fp16=fp16,
    )
```

```python
# ── model cache ──────────────────────────────────────────────────────────
_MODEL = None
_PROCESSOR = None

def _load_model(model_id: str, device: str = "cuda"):
    global _MODEL, _PROCESSOR
    if _MODEL is None:
        _PROCESSOR = AutoProcessor.from_pretrained(model_id)
        _MODEL = AutoModelForCTC.from_pretrained(model_id).to(device).eval()

# ── data types ───────────────────────────────────────────────────────────
@dataclass
class Phone:
    label: str
    start: float
    end: float

    @property
    def mid(self) -> float:
        return (self.start + self.end) / 2.0

@dataclass
class AlignResult:
    phrase_id: str
    wav_path: str
    ref_phones: int
    hyp_phones: int
    matched: int
    substitutions: int
    insertions: int
    deletions: int
    precision: float
    recall: float
    f1: float
    per_phone_errors: dict[str, int] = field(default_factory=dict)

    def to_dict(self) -> dict:
        return asdict(self)

# ── ctc decode → phone segments ──────────────────────────────────────────
def _decode_phones(wav: np.ndarray, sr: int, model_id: str, device: str) -> list[Phone]:
    if sr != 16000:
        raise ValueError(f"expected 16kHz, got {sr}")
    processor, model = _load_model(model_id, device)
    inputs = processor(wav, sampling_rate=16000, return_tensors="pt").to(device)
    with torch.inference_mode():
        logits = model(**inputs).logits[0]         # [T, V]
    pred_ids = logits.argmax(dim=-1).cpu().numpy() # [T]
    # frame stride for wav2vec2 = 20ms
    stride = 0.020
    blank_id = model.config.pad_token_id
    id_to_phone = {v: k for k, v in processor.tokenizer.get_vocab().items()}

    phones: list[Phone] = []
    current = None
    current_start = 0.0
    for t, pid in enumerate(pred_ids):
        if pid == blank_id:
            if current is not None:
                phones.append(Phone(current, current_start, t * stride))
                current = None
            continue
        lbl = id_to_phone.get(int(pid), "")
        if lbl in ("|", "<pad>", "<s>", "</s>", ""):
            if current is not None:
                phones.append(Phone(current, current_start, t * stride))
                current = None
            continue
        if lbl != current:
            if current is not None:
                phones.append(Phone(current, current_start, t * stride))
            current = lbl
            current_start = t * stride
    if current is not None:
        phones.append(Phone(current, current_start, len(pred_ids) * stride))
    return phones

# ── alignment scoring (needleman-wunsch over phoneme sequences) ──────────
def _score_alignment(ref: list[Phone], hyp: list[Phone],
                     tol: float = UTC_TOLERANCE_S) -> AlignResult:
    # DP grid: rows=ref, cols=hyp. Cost 0 for match (label + time window),
    # 1 for sub/ins/del.
    R, H = len(ref), len(hyp)
    dp = np.zeros((R + 1, H + 1), dtype=np.int32)
    for i in range(R + 1):
        dp[i, 0] = i
    for j in range(H + 1):
        dp[0, j] = j
    for i in range(1, R + 1):
        for j in range(1, H + 1):
            r, h = ref[i - 1], hyp[j - 1]
            same_label = r.label == h.label
            in_window = abs(r.mid - h.mid) <= tol
            match_cost = 0 if (same_label and in_window) else 1
            dp[i, j] = min(
                dp[i - 1, j - 1] + match_cost,
                dp[i - 1, j] + 1,   # deletion
                dp[i, j - 1] + 1,   # insertion
            )
    # backtrack to count operations
    i, j = R, H
    matched = subs = ins = dels = 0
    per_phone_errors: dict[str, int] = {}
    while i > 0 and j > 0:
        r, h = ref[i - 1], hyp[j - 1]
        same_label = r.label == h.label
        in_window = abs(r.mid - h.mid) <= tol
        match_cost = 0 if (same_label and in_window) else 1
        if dp[i, j] == dp[i - 1, j - 1] + match_cost:
            if match_cost == 0:
                matched += 1
            else:
                subs += 1
                per_phone_errors[r.label] = per_phone_errors.get(r.label, 0) + 1
            i -= 1; j -= 1
        elif dp[i, j] == dp[i - 1, j] + 1:
            dels += 1
            per_phone_errors[r.label] = per_phone_errors.get(r.label, 0) + 1
            i -= 1
        else:
            ins += 1
            j -= 1
    dels += i
    ins += j

    precision = matched / max(1, H)
    recall = matched / max(1, R)
    f1 = 2 * precision * recall / max(1e-9, precision + recall)

    return AlignResult(
        phrase_id="",
        wav_path="",
        ref_phones=R,
        hyp_phones=H,
        matched=matched,
        substitutions=subs,
        insertions=ins,
        deletions=dels,
        precision=round(precision, 4),
        recall=round(recall, 4),
        f1=round(f1, 4),
        per_phone_errors=per_phone_errors,
    )
```

## 13.6 `syncnet_wrapper.py` — lip-sync offset + confidence

```python
#!/usr/bin/env python3
"""
syncnet_wrapper.py — thin wrapper around a SyncNet checkpoint that returns
(offset_ms, confidence) for a (video, audio) pair.

Assumptions:
  - Face crop is stable across the clip (LoRA test renders use a fixed
    portrait framing; if that changes, add a face-tracker step first).
  - Video is 25 fps; audio is 16 kHz mono.
  - Checkpoint follows the s3fd + syncnet_v2 layout used by the reference
    implementation.
"""
from __future__ import annotations

import argparse
import json
import subprocess
import sys
import tempfile
from dataclasses import dataclass, asdict
from pathlib import Path

import numpy as np
import torch
import yaml

@dataclass
class SyncResult:
    video_path: str
    audio_path: str
    offset_ms: int
    confidence: float
    fps: float
    duration_s: float

    def to_dict(self) -> dict:
        return asdict(self)

# ── ffmpeg helpers ───────────────────────────────────────────────────────
def _extract_frames(video: Path, fps: int, out_dir: Path) -> int:
    out_dir.mkdir(parents=True, exist_ok=True)
    cmd = [
        "ffmpeg", "-y", "-loglevel", "error",
        "-i", str(video),
        "-vf", f"fps={fps},scale=224:224",
        "-pix_fmt", "rgb24",
        str(out_dir / "frame_%06d.png"),
    ]
    subprocess.run(cmd, check=True)
    return len(list(out_dir.glob("frame_*.png")))

def _extract_audio(video: Path, sr: int, out_wav: Path) -> None:
    cmd = [
        "ffmpeg", "-y", "-loglevel", "error",
        "-i", str(video),
        "-ac", "1", "-ar", str(sr),
        str(out_wav),
    ]
    subprocess.run(cmd, check=True)

# ── syncnet inference ────────────────────────────────────────────────────
def _load_syncnet(ckpt: Path, device: str):
    from syncnet_python.SyncNetModel import S    # vendored reference impl
    model = S(num_layers_in_fc_layers=1024).to(device).eval()
    state = torch.load(str(ckpt), map_location=device)
    model.load_state_dict(state)
    return model

def _compute_offset(model, frames_dir: Path, wav_path: Path,
                    fps: int, device: str) -> tuple[int, float]:
    """
    Returns (offset_frames, confidence). Positive offset = audio lags video.
    """
    import cv2
    import librosa
    frame_paths = sorted(frames_dir.glob("frame_*.png"))
    frames = np.stack([cv2.imread(str(p))[..., ::-1] for p in frame_paths])  # RGB
    frames_t = torch.from_numpy(frames).float().permute(0, 3, 1, 2).unsqueeze(0) / 255.0
    frames_t = frames_t.to(device)

    y, _ = librosa.load(str(wav_path), sr=16000, mono=True)
    mfcc = librosa.feature.mfcc(y=y, sr=16000, n_mfcc=13, hop_length=160, n_fft=512)
    mfcc_t = torch.from_numpy(mfcc).float().unsqueeze(0).unsqueeze(0).to(device)

    with torch.inference_mode():
        im_feat = model.forward_lip(frames_t)     # [1, D, Tv]
        au_feat = model.forward_aud(mfcc_t)       # [1, D, Ta]

    # sliding-window cosine over ±15 frames
    max_lag = 15
    scores = []
    Tv = im_feat.shape[-1]
    Ta = au_feat.shape[-1]
    T = min(Tv, Ta)
    for lag in range(-max_lag, max_lag + 1):
        if lag < 0:
            a = im_feat[..., -lag:T]
            b = au_feat[..., :T + lag]
        elif lag > 0:
            a = im_feat[..., :T - lag]
            b = au_feat[..., lag:T]
        else:
            a = im_feat[..., :T]
            b = au_feat[..., :T]
        n = min(a.shape[-1], b.shape[-1])
        a = a[..., :n]; b = b[..., :n]
        sim = torch.nn.functional.cosine_similarity(a, b, dim=1).mean().item()
        scores.append(sim)
    scores = np.array(scores)
    best = int(np.argmax(scores))
    offset_frames = best - max_lag
    # confidence = peak vs median distance, scaled
    confidence = float((scores[best] - np.median(scores)) * 20.0)
    return offset_frames, confidence

# ── public API ───────────────────────────────────────────────────────────
def score(video_path: Path, cfg: dict) -> SyncResult:
    fps = cfg["syncnet"].get("fps", 25)
    sr = cfg["syncnet"].get("audio_sr", 16000)
    ckpt = Path(cfg["syncnet"]["checkpoint"])
    device = cfg["syncnet"].get("device", "cuda")

    with tempfile.TemporaryDirectory() as td:
        td_p = Path(td)
        frames_dir = td_p / "frames"
        audio_path = td_p / "audio.wav"
        _extract_frames(video_path, fps, frames_dir)
        _extract_audio(video_path, sr, audio_path)

        model = _load_syncnet(ckpt, device)
        offset_frames, confidence = _compute_offset(
            model, frames_dir, audio_path, fps, device
        )
    offset_ms = int(round(offset_frames * 1000.0 / fps))
    import soundfile as sf
    info = sf.info(str(audio_path)) if audio_path.exists() else None
    duration_s = info.frames / info.samplerate if info else 0.0

    return SyncResult(
        video_path=str(video_path),
        audio_path=str(audio_path),
        offset_ms=offset_ms,
        confidence=round(confidence, 3),
        fps=float(fps),
        duration_s=round(duration_s, 3),
    )

def main() -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--config", default=r"D:\AI\ComfyUI_portable\workshop\scrape\audio_sync\config\audio_sync.yaml")
    ap.add_argument("--video", required=True)
    ap.add_argument("--out", default="")
    args = ap.parse_args()

    cfg = yaml.safe_load(Path(args.config).read_text(encoding="utf-8"))
    result = score(Path(args.video), cfg)
    payload = json.dumps(result.to_dict(), indent=2)
    if args.out:
        Path(args.out).write_text(payload, encoding="utf-8")
    print(payload)
    return 0

if __name__ == "__main__":
    sys.exit(main())
```

```python
# ---------------------------------------------------------------------------
# Aggregation
# ---------------------------------------------------------------------------
def _aggregate(results: list[PhraseResult], subset: str) -> AggregateMetrics:
    """
    Worst-case aggregation within a subset. We deliberately do NOT average —
    a LoRA that lip-syncs beautifully on 11 phrases and catastrophically on
    the 12th is still a LoRA that will embarrass you on the 12th phrase in
    production.
    """
    subset_results = [r for r in results if r.subset == subset]
    ok = [r for r in subset_results if r.render_ok]
    n_fail = len(subset_results) - len(ok)

    if not ok:
        return AggregateMetrics(
            sync_offset_ms=999.0,
            sync_conf=0.0,
            phoneme_f1=0.0,
            mos=0.0,
            n_phrases=len(subset_results),
            n_render_failures=n_fail,
        )

    return AggregateMetrics(
        sync_offset_ms=max(abs(r.sync_offset_ms) for r in ok),
        sync_conf=min(r.sync_conf for r in ok),
        phoneme_f1=min(r.phoneme_f1 for r in ok),
        mos=min(r.mos for r in ok),
        n_phrases=len(subset_results),
        n_render_failures=n_fail,
    )


def _worst_of(a: AggregateMetrics, b: AggregateMetrics) -> AggregateMetrics:
    return AggregateMetrics(
        sync_offset_ms=max(a.sync_offset_ms, b.sync_offset_ms),
        sync_conf=min(a.sync_conf, b.sync_conf),
        phoneme_f1=min(a.phoneme_f1, b.phoneme_f1),
        mos=min(a.mos, b.mos),
        n_phrases=a.n_phrases + b.n_phrases,
        n_render_failures=a.n_render_failures + b.n_render_failures,
    )


# ---------------------------------------------------------------------------
# Threshold gate
# ---------------------------------------------------------------------------
def _apply_thresholds(worst: AggregateMetrics, thresholds: dict) -> tuple[str, list[str]]:
    """
    Compare worst-case metrics against thresholds. Returns (verdict, reasons).

    Failure counting:
      0 failed metrics   -> promote
      1 failed metric    -> flag_review
      2+ failed metrics  -> quarantine

    Render failures compound: if >25% of phrases failed to render, verdict
    is forced to quarantine regardless of the metrics that did complete.
    """
    reasons: list[str] = []
    failed = 0

    if worst.sync_offset_ms > thresholds["sync_offset_ms_max"]:
        reasons.append(
            f"sync_offset_ms failed: got {worst.sync_offset_ms:.1f}, "
            f"need <= {thresholds['sync_offset_ms_max']}"
        )
        failed += 1

    if worst.sync_conf < thresholds["sync_conf_min"]:
        reasons.append(
            f"sync_conf failed: got {worst.sync_conf:.2f}, "
            f"need >= {thresholds['sync_conf_min']}"
        )
        failed += 1

    if worst.phoneme_f1 < thresholds["phoneme_f1_min"]:
        reasons.append(
            f"phoneme_f1 failed: got {worst.phoneme_f1:.3f}, "
            f"need >= {thresholds['phoneme_f1_min']}"
        )
        failed += 1

    if worst.mos < thresholds["mos_min"]:
        reasons.append(
            f"mos failed: got {worst.mos:.2f}, "
            f"need >= {thresholds['mos_min']}"
        )
        failed += 1

    # Render-failure override
    if worst.n_phrases > 0:
        fail_rate = worst.n_render_failures / worst.n_phrases
        if fail_rate > 0.25:
            reasons.append(
                f"render_failure_rate too high: {fail_rate:.0%} "
                f"({worst.n_render_failures}/{worst.n_phrases})"
            )
            return "quarantine", reasons

    if failed == 0:
        return "promote", reasons
    if failed == 1:
        return "flag_review", reasons
    return "quarantine", reasons

    """
    t0 = time.monotonic()
    lora_path = Path(lora_path)
    workdir = Path(workdir)
    workdir.mkdir(parents=True, exist_ok=True)

    if config is None:
        config = _load_config(DEFAULT_CONFIG)

    thresholds = config["thresholds"]
    phrase_bank = _load_phrase_bank(PHRASE_BANK)

    # Optional subset filter (config lets you dry-run on SFW only)
    subsets_enabled = set(config["test_matrix"].get("subsets", ["sfw", "nsfw"]))
    phrase_bank = [p for p in phrase_bank if p["subset"] in subsets_enabled]

    # Optional phrase cap for smoke tests
    cap = config["test_matrix"].get("max_phrases")
    if cap:
        phrase_bank = phrase_bank[:cap]

    print(f"[scorecard] {lora_path.name}: sweeping {len(phrase_bank)} phrases")

    results: list[PhraseResult] = []
    for i, phrase in enumerate(phrase_bank, 1):
        print(f"[scorecard]   [{i:02d}/{len(phrase_bank)}] {phrase['id']} ({phrase['subset']})")
        r = _score_phrase(lora_path, phrase, workdir, config)
        results.append(r)
        if not r.render_ok:
            print(f"[scorecard]     ! {r.error}")
        else:
            print(
                f"[scorecard]     off={r.sync_offset_ms:+5.1f}ms  "
                f"conf={r.sync_conf:4.2f}  f1={r.phoneme_f1:.3f}  mos={r.mos:.2f}"
            )

    agg_sfw = _aggregate(results, "sfw")
    agg_nsfw = _aggregate(results, "nsfw")
    worst = _worst_of(agg_sfw, agg_nsfw)

    verdict, reasons = _apply_thresholds(worst, thresholds)

    card = Scorecard(
        lora=lora_path.name,
        sha256=_sha256_file(lora_path),
        verdict=verdict,
        reasons=reasons,
        per_phrase=[r.as_row() for r in results],
        aggregate={
            "sfw": agg_sfw.as_dict(),
            "nsfw": agg_nsfw.as_dict(),
            "worst": worst.as_dict(),
        },
        thresholds=thresholds,
        elapsed_s=round(time.monotonic() - t0, 1),
        ran_at=datetime.now(timezone.utc).isoformat(timespec="seconds"),
    )

    # Persist scorecard next to the workdir for sandbox_test.py to pick up
    out_path = workdir / f"{lora_path.stem}.audiosync.scorecard.json"
    tmp = out_path.with_suffix(".json.tmp")
    tmp.write_text(json.dumps(card.as_dict(), indent=2), encoding="utf-8")
    tmp.replace(out_path)
    print(f"[scorecard] {lora_path.name}: verdict={verdict}  elapsed={card.elapsed_s}s")
    for reason in reasons:
        print(f"[scorecard]   reason: {reason}")

    return card.as_dict()


# ---------------------------------------------------------------------------
# CLI
# ---------------------------------------------------------------------------
def _main() -> int:
    ap = argparse.ArgumentParser(description="Audio-sync scorecard runner")
    ap.add_argument("--lora", required=True, type=Path, help="Path to candidate .safetensors")
    ap.add_argument("--workdir", required=True, type=Path, help="Scratch dir for renders")
    ap.add_argument("--config", type=Path, default=DEFAULT_CONFIG)
    ap.add_argument("--out", type=Path, help="Explicit scorecard output path (optional)")
    args = ap.parse_args()

    try:
        config = _load_config(args.config)
        card = run(args.lora, args.workdir, config)
    except Exception as e:
        print(f"[scorecard] FATAL: {e.__class__.__name__}: {e}", file=sys.stderr)
        traceback.print_exc()
        return 3

    if args.out:
        args.out.write_text(json.dumps(card, indent=2), encoding="utf-8")

    return {"promote": 0, "flag_review": 1, "quarantine": 2}[card["verdict"]]


if __name__ == "__main__":
    sys.exit(_main())
```

## R.3 Reading the scorecard

`scorecard.py` writes three artifacts to `--workdir`:

```txt
<workdir>/
  scorecard.json          ← canonical machine-readable verdict + all metrics
  scorecard.md            ← human-readable summary, safe to paste into review
  renders/
    <phrase_id>/
      driving_audio.wav
      generated.mp4
      metrics.json        ← per-phrase raw numbers (F1, sync_offset, sync_conf, mos)
```

The one thing to eyeball first is `scorecard.md`. Structure:

```txt
# LoRA: lipsync_v2.safetensors
verdict: flag_review  (exit 10)
generated: 2026-09-21T08:14:23Z
phrases:   16/16 rendered

## Aggregate metrics
  phoneme_f1     : 0.812   (threshold ≥ 0.78 promote, ≥ 0.72 flag)  ✓
  sync_offset    : 2.1 frm (threshold ≤ 2   promote, ≤ 4    flag)  ⚠ flag
  sync_conf      : 7.4     (threshold ≥ 7.0 promote, ≥ 5.5  flag)  ✓
  utmos          : 3.61    (threshold ≥ 3.7 promote, ≥ 3.3  flag)  ⚠ flag
  viseme_collide : 0.04    (threshold ≤ 0.06 promote, ≤ 0.10 flag) ✓

## Failing phrases (>2σ from mean on any metric)
  p_007  sync_offset=4.2 frm   (mean 2.1, σ 0.9)
  p_013  utmos=3.11           (mean 3.61, σ 0.18)

## Recommendation
  Two metrics borderline (sync_offset, utmos). Operator review advised.
  If promoted, tag with weight_ceiling=0.75 to compensate.
```

If verdict is `promote`, the `promote_trigger.ps1` wrapper (Part 7) picks up `scorecard.json` automatically and calls `promote.py`. You don't have to do anything.

If verdict is `flag_review`, the LoRA sits in `loras/staging/` until an operator runs:

```powershell

# or

```

If verdict is `quarantine`, `promote.py --auto` picks it up and moves the file to `loras/quarantine/<YYYYMMDD>/` with the scorecard bundled alongside as the paper trail.

## R.5 Operator triage — when scorecard.py misbehaves

**Symptom: exit 30 (`render_failed`) on every candidate.**
ComfyUI service is down or the probe workflow references a checkpoint that isn't installed. Check:

```powershell
Get-Service ComfyUI -ErrorAction SilentlyContinue
Invoke-WebRequest http://127.0.0.1:8188/system_stats -UseBasicParsing | Select -ExpandProperty Content
Test-Path "D:\AI\ComfyUI_portable\ComfyUI\models\checkpoints\<probe_checkpoint>.safetensors"
```

If ComfyUI is up but the probe checkpoint is missing, edit `config/audio_sync.yaml` → `probe.checkpoint` to point at whatever base model is actually present, then re-run.

**Symptom: exit 40 (`metric_error`) with `CUDA out of memory` in the traceback.**
SyncNet + UTMOS + wav2vec2 loaded concurrently pushes ~7 GB on top of the ComfyUI render. If another process is holding VRAM, scorecard evicts and crashes. Force serial metric evaluation:

```powershell
python scorecard.py --lora "..." --workdir "..." --serial-metrics
```

This costs ~40% wallclock but survives on a shared 5090.

**Symptom: exit 40 with `phoneme_align: no frames aligned`.**
The generated video has no detectable lip motion — either the LoRA is dead, or the probe workflow rendered a static image sequence. Sanity check by opening one of the `renders/<phrase_id>/generated.mp4` files. If it's static, the LoRA loaded at strength 0.0 or failed to inject; check `sandbox_test.py` output for that candidate.

**Symptom: exit 40 with `syncnet: input too short`.**
Phrase bank has entries shorter than SyncNet's minimum window (~1.0s at 25fps). Regenerate the affected phrase or filter it:

```powershell
python -c "import json; [print(l) for l in open('phrase_bank.jsonl',encoding='utf-8') if json.loads(l)['duration_s'] < 1.0]"
```

Remove or lengthen those entries; they should never have been in the bank.

**Symptom: verdict is `promote` but downstream `promote.py --auto` refuses.**
`promote.py` re-validates the scorecard signature (Part 7 §7.4). If `scorecard.json`'s `signature` field doesn't match a recomputation over the metric fields, promote refuses. Regenerate:

```powershell
python scorecard.py --lora "..." --workdir "..." --skip-render --resign
```

**Symptom: same LoRA keeps getting `flag_review` cycle after cycle.**
Two failure modes: (a) the LoRA is genuinely borderline and needs a `weight_ceiling` note before promotion, or (b) one phrase in the bank is a persistent outlier. Check `scorecard.md` → `Failing phrases`. If the same `p_XXX` appears three cycles running, the phrase is the problem, not the LoRA. Bank it separately in `phrase_bank.suspect.jsonl` for review.

## R.6 Cache & workspace hygiene

`--workdir` accumulates render artifacts fast — a full 16-phrase sweep is ~800 MB of MP4/WAV per candidate. Weekly cleanup:

```powershell
# Purge scorecard workdirs older than 14 days, keeping the scorecard.json + scorecard.md.
Get-ChildItem "D:\AI\ComfyUI_portable\workshop\scrape\out\audiosync" -Directory |
  Where-Object { $_.LastWriteTime -lt (Get-Date).AddDays(-14) } |
  ForEach-Object {
    $keep = Join-Path $_.FullName "scorecard.json"
    $keepMd = Join-Path $_.FullName "scorecard.md"
    if (Test-Path $keep) {
      Get-ChildItem $_.FullName -Recurse -File |
        Where-Object { $_.FullName -ne $keep -and $_.FullName -ne $keepMd } |
        Remove-Item -Force
      Get-ChildItem $_.FullName -Recurse -Directory |
        Sort-Object FullName -Descending | Remove-Item -Force -Recurse -ErrorAction SilentlyContinue
    }
  }
```

The scorecards themselves are tiny (~4 KB each) and stay forever — they're the historical record that feeds `audit_matrix.py`'s trend analysis.
